# ADR — Architecture Decision Records (documentation d'architecture)

Ce répertoire contient les ADR **propres à la documentation d'architecture** (arc42, diagrammes,
scénarios qualité). Les décisions architecturales du projet NEXUS se trouvent dans
[`docs/adr/`](../../adr/README.md) (ADR-0000 à ADR-0044).

## Quand créer un ADR ici ?

Créer un ADR dans ce répertoire uniquement lorsqu'une décision concerne :

- la structure ou la convention de la documentation d'architecture elle-même ;
- le choix d'un outil de documentation (framework, format, outil de génération) ;
- la stratégie de mise à jour ou de vérification de la cohérence docs/code.

## Modèle

Voir [`template.md`](template.md) pour la structure d'un ADR.
